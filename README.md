# AImotion

AImotion is a web application for creating animations and video plans using a node editor and a Python backend.

## Project Structure

- `frontend/` — React application and node editor
- `backend/` — Python FastAPI service and validation/orchestration logic
- `workers/` — Celery tasks and multimedia processing
- `providers/` — Cloud provider adapters and local bridges
- `tests/` — Unit and integration tests
- `config/` — Configuration and environment examples
- `docs/` — Project documentation
